Cara Penggunaan

  1. Upload Audio: Masukkan file berformat MP3 atau WAV.
  2. Input Lirik: Ketik atau tempel (paste) lirik Anda. Pisahkan setiap bait dengan tombol Enter. Klik "Load Lirik".
  3. Sinkronisasi: Putar lagu, lalu klik tombol Sync pada baris lirik yang tepat saat penyanyi menyanyikannya.
  4. Kustomisasi: Pilih atau buat tema visual di bagian Theme Marketplace.
  5. Ekspor: Pilih resolusi, lalu klik "Export Video" untuk merender video MP4/WebM secara offline.

Arsitektur (Untuk Developer)

Aplikasi ini dibangun menggunakan pola Clean Architecture dan ES Modules tanpa framework eksternal.

  • core/ - Berisi EventBus (Pub/Sub), Global State, dan Plugin Manager.
  • modules/ - Komponen terisolasi dengan tanggung jawab tunggal (Single Responsibility Principle).
  • plugins/ - Ekstensi pihak ketiga yang berinteraksi via Hook (BEFORE_RENDER, AFTER_RENDER).
